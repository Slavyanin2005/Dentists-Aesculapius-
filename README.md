# Сайт стоматологии «Эскулап»

Статический многостраничный сайт ООО «ЭСКУЛАП» для клиники в районе Талнах города Норильска.

## Запуск

Сайт не требует базы данных, backend, Python-окружения или установки зависимостей.

Можно открыть `index.html` напрямую либо запустить любой статический HTTP-сервер из корня проекта, например:

```powershell
node tools/serve.mjs
```

После запуска сайт доступен по адресу `http://localhost:4173`.

## Структура

- `index.html` — главная;
- `services.html` — услуги и цены;
- `doctors.html` — врачи;
- `patients.html` — информация для пациентов и анкета;
- `documents.html` — лицензия и обязательные сведения;
- `contacts.html` — контакты и маршруты;
- `privacy.html` — предварительная политика обработки персональных данных;
- `sitemap.html` — навигация по сайту;
- `assets/` — стили, JavaScript и изображения документов;
- `media/` — логотипы.

## Перед публикацией

Необходимо добавить сведения об образовании и аккредитации врачей, подтвердить актуальность прайс-листа и контактов контролирующих органов, получить исходную PDF-выписку из реестра лицензий и утвердить юридические документы.
